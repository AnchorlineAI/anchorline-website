[Shopify introduced Canvas on October 1](https://www.shopify.com/news/introducing-canvas), a workspace where you can describe the store you want to Sidekick and watch it take shape across multiple pages. Shopify says the agent changes actual theme files, checks its code and reviews screenshots as it works.

I'm excited about this. An owner can have a pretty clear idea of how a store should feel without knowing how to build it. Being able to explain that idea, see something real and keep working on it could make a project feel possible much earlier.

There's a useful distinction in [Shopify's instructions](https://help.shopify.com/en/manual/online-store/themes/canvas/customizing): saving and publishing are separate. Canvas saves changes automatically, but customers don't see them until they're published. You can duplicate a supported theme to experiment, and version history lets you restore earlier work.

It's early access, though. [Shopify's current limits](https://help.shopify.com/en/manual/online-store/themes/canvas/requirements) include desktop-only access and no third-party theme support. Themes edited in Canvas don't receive theme updates, and you can't add or configure app blocks there. Those details matter before moving an existing store into it.

I'd start with a copy and one customer question. Can someone understand the product, find the information they need and get to the next step on a phone? Try a change and walk through it. The interesting part is having room to explore an idea without every revision becoming a separate development project.
